# DevKit JSON 与国际时区增强设计

**日期：** 2026-08-24

## 目标

在现有 PC 端静态工具站中增强 JSON 与时间戳工具：加入本地历史、JSON 树形折叠、文本转义/去转义，以及覆盖国际化业务常用区域的 IANA 时区显示和日期反向转换。

## 决策

### JSON 历史

- 最多保存最近 20 条成功处理记录，采用新记录优先。
- 保存格式化、压缩、转义、去转义四类操作的输入、输出、操作类型和时间。
- 相同操作与相同输入去重并置顶，不保存失败或空输入。
- 使用 `localStorage`，键名为 `devkit.json.history.v1`；存储异常或损坏数据不得影响工具使用。
- 支持恢复、单条删除、全部清空，并明确说明历史只存于当前浏览器。
- 这项需求覆盖原设计“不使用持久化存储”的限制；仍不产生任何网络请求。

### JSON 折叠视图

- 文本结果继续作为复制和历史保存的权威结果。
- 成功格式化或压缩合法 JSON 后，可切换到树形折叠视图。
- 对象和数组使用嵌套 `details/summary`；默认展开根节点和第一层容器。
- 支持全部展开和全部收起；键、字符串、数字、布尔值与 `null` 有不同语义样式。
- 所有值通过 DOM `textContent` 渲染，禁止拼接用户 HTML。
- 转义或去转义结果不是合法 JSON 时，折叠按钮禁用并给出说明。

### 转义与去转义

- “转义”把输入文本转为适合放入 JSON 字符串内部的内容，处理引号、反斜杠、换行、制表符等。
- “去转义”接受带外层双引号的 JSON 字符串或不带外层引号的转义内容。
- 去转义结果必须是字符串；无效转义返回可读错误且保留原输入。
- 成功结果进入统一输出、复制、计数和历史流程。

### 国际时区

- 使用浏览器原生 `Intl.DateTimeFormat` 与 IANA 时区标识，不引入时区依赖。
- 时区选择按 UTC、浏览器本地、美洲、欧洲、亚洲/中东、非洲和大洋洲分组。
- 提供至少：UTC、New York、Los Angeles、Chicago、Toronto、São Paulo、Mexico City、London、Paris、Berlin、Amsterdam、Moscow、Shanghai、Hong Kong、Tokyo、Seoul、Singapore、Kolkata、Dubai、Cairo、Johannesburg、Lagos、Sydney、Auckland。
- 时间戳转日期增加“所选区域时间”和时区标识，同时保留浏览器本地、UTC、ISO 和相对时间。
- 日期转时间戳将输入的墙上时间解释为所选 IANA 时区；UTC 与浏览器本地继续兼容。
- 对不存在的 IANA 时区、日期越界以及夏令时跳变导致的不存在本地时间返回错误。
- 夏令时回拨产生的重复时间选择算法找到的第一个有效时刻，不额外要求用户选择早/晚偏移。
- “使用当前时间”按所选时区填充日期和时间。

## 文件边界

- `assets/js/json-core.mjs`：增加纯函数转义与去转义。
- `assets/js/json-history.mjs`：封装历史规范化、去重、限制和存储异常处理。
- `assets/js/timestamp-core.mjs`：增加 IANA 时区格式化、墙上时间解析与时区验证。
- `assets/js/app.mjs`：绑定历史、折叠树、时区选择和新操作。
- `index.html`：增加历史面板、折叠容器、新按钮与时区选择。
- `assets/styles.css`：增加 PC 端历史、树形 JSON、时区控件样式。
- `tests/`：覆盖新纯函数、存储边界、时区/DST 和关键 DOM 交互。

## 验收

- 历史最多 20 条、可恢复/删除/清空，刷新页面后仍存在。
- 转义与去转义对 Unicode、引号、反斜杠、换行和无效序列行为正确。
- 树形视图可逐层、全部展开和全部折叠，不执行输入中的 HTML。
- 同一时间戳能显示所选国际时区；国际墙上时间可正确反向生成 Unix 时间戳。
- New York 夏令时不存在时间被拒绝，常见冬夏时偏移转换正确。
- 所有既有测试、新增测试、构建和 PC 浏览器验收通过后推送 `main`。
